## 3. 核心业务流程推测

根据用户操作，该系统解决的是 **KOL/红人营销项目管理与执行** 的业务问题。

**流程如下：**
1.  **基础数据维护**: 录入客户（Brand）和项目（Campaign），设定预算和平台。
2.  **需求发起 (Demand)**: 运营或销售在“需求工单”中填写捞取红人的具体需求（如：Instagram平台，美国地区，10k-50k粉丝，关键词lifestyle）。系统可能通过AI或规则自动从“资料库”捞取红人。
3.  **任务执行 (Execute)**: 在“执行工单”中，将需求工单分配给具体的运营人员（主/副），运营人员从资料库中筛选红人，进行建联和提报。
4.  **数据沉淀 (Database)**: “资料库”存储各平台（IG, YT, TT）的红人基础数据和报价状态。
5.  **结果统计 (Statistics)**: 通过“统计”模块查看项目的财务数据（签约、回款、毛利）和运营效率（审核数、上线数、提报率）。

### E. 关键业务实体
*   **客户 (Customer)**: 品牌方 (如 Bigo Live, 追觅, Mova)。
*   **项目 (Project)**: 具体的营销活动 (如 xx26推广, Mova欧区-新品)。

*   **执行工单 (Execute Order)**: 分配给运营的具体任务单。
*   **红人 (Influencer/Red)**: 资料库中的博主数据。
*   **运营人员 (Operator)**: 负责执行任务的用户。

### F. 系统整体功能架构
*   **前端**: 基于 Web 的 SaaS 应用 (MercuryDynamic)。
*   **核心业务流**: CRM (客户/项目) -> 订单流 (需求/执行工单) -> 资源库 (红人数据) -> 财务/BI (统计)。
