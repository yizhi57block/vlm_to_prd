# MercuryDynamic · 视频人工梳理 — 功能树

> 本文档仅依据视频人工梳理内容整理，不参考既有需求/分析文档。

---

## 1. 角色说明

| 角色 | 说明 |
|------|------|
| 超级管理员 | 可见全部菜单 |
| 运营 | 视频中示例账号名为「姚瑶」；可见公共菜单 + 运营专属菜单 |
| 经理 | 可见公共菜单 + 经理专属菜单 |

约定：

- **公共**：运营、经理均可看到
- **运营**：仅运营可见（超级管理员也可见）
- **经理**：仅经理可见（超级管理员也可见）

---

## 2. 菜单与页面约定

- 一级菜单原则上只做分类，**不对应具体页面**
- 例外：一级菜单「首页」有对应页面（整体数据 Dashboard 大盘）
- 其余可访问页面均落在二级菜单（或更深层级）上

## 7. 页面功能明细

### 7.1 客户 / 客户管理 【经理】

#### 页面形态

客户列表页（表格）。

#### 列表列

| 列名 | 说明 |
|------|------|
| 客户全称 | 必填字段，列表展示 |
| 客户简称 | 必填字段，列表展示 |
| 项目经理归属 | 必填字段；关联用户 id |
| 企业地址 | 可缺省 |
| 省份 | 可缺省 |
| 客户行业 | 可缺省 |
| 获取渠道 | 可缺省 |
| 客户等级 | 可缺省（是否有默认值 → 见待澄清） |
| 商务归属 | 可缺省；关联用户 id |
| 所属部门 | 可缺省 |
| 操作 | 行操作区 |

另：视频提到存在**隐藏字段**（细节待补）。

#### 必填规则（新增/编辑表单）

仅以下三项不可缺省，表单须必填：

1. 客户全称
2. 客户简称
3. 项目经理归属

其余字段均可缺省。

#### 查询

- 可按：**客户全称**、**客户等级** 查询
- 查询按钮旁有：**重置**

#### 新增

- 有「新增」按钮，打开表单
- 表单字段覆盖上表所列客户信息
- **项目经理归属**、**商务归属**：均需关联到用户 id（可选用户范围是否分角色 → 见待澄清）
- 表单底部可**同时新增联系人**（写入该客户下的联系人）

#### 与联系人关系

- 客户 : 客户联系人 = **1 : N**
- 在客户新增表单底部即可挂接联系人；联系人字段见 §7.2
